# IGR Consulting — Especificação Canônica

Este diretório registra a base de decisão para o **IGR Consulting**, uma plataforma de planejamento de operações de multipropriedade. Os documentos mantêm separadas as decisões verificadas, as premissas configuráveis e os itens ainda pendentes. O produto deve seguir a cadeia **Planejar → Simular → Decidir → Apresentar → Aprovar → Exportar**.

| Documento                            | Finalidade                                                             |
| ------------------------------------ | ---------------------------------------------------------------------- |
| `00_STUDY_REPORT.md`                 | Entendimento do produto, invariantes, fontes donor e pontos pendentes. |
| `01_TECHNICAL_DISCOVERY.md`          | Pesquisa validada de frameworks, engines e licenças.                   |
| `02_ARCHITECTURE_DECISION_RECORD.md` | Decisões Build, Buy e Reuse; limites do ambiente.                      |
| `03_PRD_V1.md`                       | Requisitos de produto, critérios de aceite e waves.                    |
| `04_RISK_AND_QA_MATRIX.md`           | Riscos, controles, testes e definição de pronto.                       |

> Nenhuma premissa financeira pendente deve ser preenchida por inferência, conveniência visual ou valor de demonstração. Um dado desconhecido continua `PENDENTE` até ser informado e aprovado.
