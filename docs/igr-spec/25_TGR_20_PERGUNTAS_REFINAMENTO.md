# TGR Consulting — 20 Perguntas de Refinamento

## Como responder

Não precisa responder com tese de doutorado, patrão. Pode mandar áudio, mensagem curta ou até “não sei ainda”. Se não estiver definido, eu marco como **PENDENTE**. O único pecado é transformar “não sei” em R$ 0 escondido igual rato de planilha.
